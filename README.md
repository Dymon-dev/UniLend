# UniLend: Smart Finance for Students

A front-end prototype for an entrepreneurship class project: a student-focused
finance app with low-interest loans, expense tracking, and simulated transfers.

> **Demo only.** This is NOT a real banking or financial service. All data is
> mock data stored in the browser's localStorage. Authentication is simulated
> and NOT secure. Never enter a real password or personal financial information.

## Tech
HTML, CSS, and vanilla JavaScript (ES modules). No frameworks, no backend.

## Run it
Open the project folder in VS Code and use the Live Server extension to open
`html/index.html`. (ES modules don't work when opening files by double-click.)

## Production notes
A real version would need a backend with secure authentication, password
hashing, server-side transaction validation, a database, HTTPS, a real identity
verification provider, and a licensed payment provider.
